# 🌾 Crop Advisory Text Summarization

This project generates short and useful crop advisory for farmers using NLP and transformer models.

---

## 🚀 Overview
The system takes crop-related data and generates a summarized advisory using transformer models like BART, T5, and PEGASUS.  
It helps convert complex agricultural insights into simple, farmer-friendly recommendations.

---

## 🛠️ Tech Stack
- Python  
- HuggingFace Transformers  
- BART, T5, PEGASUS  
- NLTK  
- Pandas, NumPy  

---

## 📊 Features
- Text summarization using transformer models  
- Dataset preprocessing and cleaning  
- Fine-tuning multiple pre-trained models  
- Performance evaluation using ROUGE & BLEU  

---

## 📈 Results (Best Performance)
- **ROUGE-1:** 0.41  
- **BLEU:** 0.37  

---

## 🤖 Models Used
- BART (facebook/bart-large-cnn)  
- T5 (t5-small / t5-base)  
- PEGASUS  

---

## ⚙️ Fine-Tuning
- Fine-tuned multiple transformer models on crop advisory dataset  
- Applied dataset cleaning and preprocessing  
- Used tokenization and sequence-to-sequence training  
- Compared model performance using ROUGE and BLEU scores  
- Selected best-performing model for final output  

---

## 📊 Model Comparison

| Model   | ROUGE-1 | BLEU |
|--------|--------|------|
| BART   | 0.34   | 0.16 |
| T5     | 0.41   | 0.22 |
| PEGASUS| 0.39   | 0.37 |
